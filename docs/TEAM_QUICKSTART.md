# 队友使用说明

## v0.2.0-rc.1 新版内测安装包（2026-11-04）

下载 [新版候选发布页](https://github.com/pocket996/faceguard/releases/tag/v0.2.0-rc.1) 中的 `FaceGuard-v0.2.0-rc.1-windows-x64-cpu-setup.exe`。此版本供干净电脑验证，支持 Windows 10/11 Intel / AMD 64 位；不需要 Python、CUDA、独显或训练数据。安装程序默认为当前用户安装到 `%LOCALAPPDATA%\Programs\FaceGuard`，创建桌面与开始菜单“谛听 FaceGuard”快捷方式，之后直接双击快捷方式即可，无命令行窗口；桌面入口可以在安装步骤中取消勾选。卸载入口在 Windows 应用列表，卸载保留设置、日志和检测历史。

新版包含当前水墨工作台 / 桌宠、照片与视频双项、热力图方向 / 方法、图示导出与完整稳定 / 候选模型；稳定检测权重及默认选择未改。视频生成项仍仅是照片模型的采样人脸线索，不保证整段真假。程序只在本机读取媒体；安装包不带测试素材，请使用自己的照片 / 视频。

本包尚未代码签名，Windows 可能显示未知发布者；发布页附 `SHA256SUMS.txt`，用于核对下载字节。启动失败可查看 `%LOCALAPPDATA%\FaceGuard\startup.log`，反馈时带软件版本与日志即可，无需发送个人图片。请在干净电脑检查安装及两个快捷方式、照片 / 带音轨视频预览与检测、两个任务的热力图、PDF / TXT、历史重开和桌宠悬停，再反馈系统 / CPU / 显卡及错误；本机验证不能替代这次独立验收。

本机已验证实际安装到中文 / 空格目录、中文素材名、桌面与开始菜单无窗口启动、CPU 双项与热图 / 报告 / 历史、重装和卸载；原有一份历史数据库字节保持一致。92 项测试通过；界面自动检查使用定向 Qt 事件，快捷方式另经 Windows Shell 实际启动检查。发布文件 496,106,901 字节（约 473 MiB），GitHub 服务器 SHA-256 与本地一致，随附 [验证收据](https://github.com/pocket996/faceguard/releases/download/v0.2.0-rc.1/release-validation.json)。代码见 [PR #5](https://github.com/pocket996/faceguard/pull/5)，发布包构建提交为 `f0e9e15`，PR 尚未合并到 main。

## 源码环境创建桌面入口

已经按下文准备 `.venv` 后，在项目根目录仅执行一次：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/create_shortcut.ps1
```

该快捷方式直接指向项目 `.venv\Scripts\pythonw.exe` 和 `run_app.pyw`，以后双击桌面“谛听 FaceGuard”，无需进入文件管理器寻找 CMD。源码入口仍保留 `run_app.cmd` / `run_app.py` 供诊断；源码快捷方式要求项目与虚拟环境保留在原位置，面向普通用户应使用上述安装包。

### 构建新版安装包

在独立 Windows x64 构建环境安装 `requirements-release.txt`，不要使用 CUDA 训练环境打包。安装官方 Inno Setup 后执行：

```powershell
py -3.11 -m venv outputs/release-build-env
.\outputs\release-build-env\Scripts\python.exe -m pip install -r requirements-release.txt
.\outputs\release-build-env\Scripts\python.exe scripts/build_windows_release.py --iscc "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

构建物只写入 `outputs/`，默认包含 CPU 运行时、当前正式界面资源及全部 13 份稳定 / 候选模型资源文件；PyInstaller 窗口子系统避免创建控制台，Inno Setup 为当前用户创建快捷方式与卸载入口。脚本核对模型 manifest、复制字节、冻结源码指纹，生成 `BUILD_INFO.json` / `SHA256SUMS.txt`；`--skip-freeze` 仅允许冻结源码未变时重新组装文档 / 构建元数据，修改源码后必须重新冻结。`--portable` 可额外生成完整解压式 ZIP。

维护者可用 `scripts/check_windows_package.py --setup <安装程序> --output <全新输出目录> --photo <本机照片> --video <本机视频>` 实际安装到隔离的中文 / 空格路径、检查快捷方式与无控制台启动、清除开发路径后做 CPU 双项检测 / 热图 / 报告 / 历史验证，并检查重装及卸载；测试会恢复原源码桌面快捷方式，遇到已有同名开始菜单组则停止，避免覆盖用户现有安装。验证素材只读，不写入安装包。正式程序的 `--verify-install <JSON路径>` 是显式诊断入口，正常启动不会自动运行检测。

## 正式项目：谛听检测应用（2026-10-31）

正式应用代码在 `src/faceguard/`，源码诊断入口为 `run_app.cmd` / `run_app.py`，日常无窗口入口为 `run_app.pyw` 及桌面快捷方式。首次在根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-ui.txt
.\.venv\Scripts\python.exe run_app.py
```

以后使用上方创建的桌面快捷方式；`run_app.cmd` 保留用于查看诊断输出。Qt Quick 3D 蒙皮与水面倒影需要可用的图形驱动；只预览界面可不加载模型；实际检测需要项目推理依赖与完整 `weights/runtime/`，不需要训练数据。开发分支同时提交 runtime 稳定资源、四个已安装候选及配套 manifest，队友拉取同一分支即可取得，合入主分支后再从 main 更新。离线转移时需复制完整目录并保留原始字节，正式运行不依赖 `reference_run`；普通用户使用本文件顶部的新版 CPU 安装包。

1. 在左侧选择或拖入本机照片 / 视频，照片支持放大，视频支持静音播放 / 暂停。视频预览禁用音轨解码，开始检测时自动暂停预览。文件不会上传网络。
2. 水墨远山、廊亭、月门和湖面铺满整个工作台，在左右操作区后方延伸；水岸附近仅三朵淡莲点缀；角色保留原端坐造型，以固定脚掌、接触暗部、脚边涟漪和同帧淡倒影衔接水面。工作台 / 桌宠均为 23 骨骼真实 3D 蒙皮角色，含呼吸、尾摆、眨眼和双眉 / 下颌轻微表情。点击可点头回应；开始检测后低头侧耳，双耳错时轻抖、回弹并在持续倾听时做小幅调整，结束、失败或取消完成后从当前姿态平滑回待机。减少动态效果时角色、背景视差、水纹和倒影全部静止，检测继续。进入历史 / 结果页后卸载背景并暂停角色，返回恢复；桌宠无庭景、水纹或倒影。古建 / 远山仍为绘制素材，未称完整三维园林。
3. 点击右上角“收为桌宠”，主工作台切换为透明小窗口，平时仅显示角色；鼠标移入桌宠区域后显示上下提示与“照片 / 视频 / 展开”按钮，移到按钮上保持显示，移出后隐藏。拖动角色调整位置；双击或点击“展开”返回工作台，所选文件保留。也可通过 `run_app.py --pet` 直接启动桌宠。
4. 右键角色可选择媒体、置顶、减少动效、暂时隐藏和退出。隐藏后从系统托盘双击恢复；不支持托盘时改为最小化。设置与桌宠停靠位置保存在本机。
5. 导入后点击“开始检测”，照片与视频均分别检查 AI 整脸生成及面部篡改。视频生成项使用照片模型与原照片阈值分析采样人脸，仅提示逐帧生成线索，尚未标定整段视频结论 / 误报率，不分析音频或整幅场景；篡改项保留原 16 帧基线与局部复核。两项各自最多 96 帧覆盖 + 48 帧复核，同一人可能多次出现，不把帧数当独立人数。按钮可取消，后台加载模型或当前采样步骤结束后响应取消。进度按实际阶段与样本数量显示；两项分数不合并，倾听动作与实际后台检测状态联动。旧视频历史仍保留当时仅篡改的结果，需要重新检测才补生成项。
6. 检测完成后保留工作台，右侧显示结果概览；点击“查看结果与热力图”进入结果页并选中第一条人脸。选择右侧人脸 / 检测项目，视频显示对应采样帧；上方“解释方向”可选生成 / 篡改线索或未检出方向，“方式”可选梯度关注或遮挡对照，后者逐块轻度模糊人脸并检查模型响应。可切换原图、叠加、并排，调整强度并同步缩放拖动。蓝黄红表示该图内相对响应，不能跨图比较或当作真假概率；低于提示阈值仍可能有颜色，全零保持透明。两种方式均只作辅助解释，当前小样本诊断没有证明正类红区可可靠定位；未检出方向也不证明真实。方法 / 方向分开随历史保存，旧梯度缓存仍可读；模型复用有数量上限，计算可取消，连续选择仅处理最后一项。模型 / 原文件变化时要求重新检测。新增“导出当前图示”可选 PNG / PDF，保存当前原图与叠加对比、所选脸 / 帧、方向、版本、图例和说明；“保存检测报告”仍默认 PDF、可选 TXT，保持文字报告。技术详情在“设置”，训练候选在默认收起的“高级选项”。
7. 右上角“历史”位于“设置”旁，可搜索文件名、筛选照片 / 视频、重新打开、删除与清空。记录保存在本机应用数据目录的 SQLite 库，保存路径、导入信息和真实检测结果，不复制原文件。导入时为“待检测”，检测后记录完成 / 部分完成 / 失败 / 取消状态；重新打开可恢复结果且不重复记一条，文件大小或修改时间变化后要求重新检测，文件移动后会提示找不到。清除记录不删除原始文件。
8. **设置 → 角色立体预览** 打开同一形象的 23 骨骼真实 3D 谛听，默认播放呼吸 / 摆尾与眨眼；眼睛已分层为眼白、虹膜、凹入瞳孔与透明凸角膜，反光随视角变化；点头 / 侧耳倾听含预备、停留与回弹，播完回到待机，支持暂停 / 继续。拖动、滚轮或按钮可旋转，恢复朝向可回到主视角；关闭后卸载预览。减少动态效果时静止，动作按钮禁用。工作台和桌宠已经接入同版骨骼资源；当前为端坐表演，张嘴 / 舌牙、四足站立 / 行走及跨窗口移动仍未制作，口鼻、折耳和材质接缝仍需精修。

2026-10-30 交互补充：桌宠展开 / 收起增加淡出淡入与连续点击保护，开启“减少动态效果”则立即切换；这不是角色跨窗口行走。点击角色点头回应，悬停联动背景轻微视差，双击可在工作台 / 桌宠间切换，拖动超过阈值后才移动桌宠。结果页并排图同步缩放与拖动，点击“适应”复位。快捷键：`Ctrl+O` 选择照片、`Ctrl+Shift+O` 选择视频、`Ctrl+H` 历史、`Ctrl+R` 结果、`F1` 说明；`Esc` 关闭弹窗。

角色源图使用内置 imagegen 以原设定为参考生成，保存在 `src/faceguard/ui/assets/diting-v2.png`；当前运行使用 `diting-motion-v7/` 真实蒙皮资源，旧图保留溯源，制作与背景生成提示词见同目录 README。坐姿表演、眼睑、双眉和下颌已有控制，张嘴 / 完整面部 / 四足行走绑定、桌宠连续走入中央 / 返回停靠点与自由巡游尚未完成。透明窗口的周边仍属于矩形窗口输入范围；多显示器、不同 DPI、视频编码兼容和其他队友机器仍需实际验收。

## 已有参考项目：v0.1.0 免安装包

这个发布包适用于 **Windows 10/11，64 位 Intel/AMD 电脑**。它已经包含 Python、CPU 检测程序和两份模型；不需要安装 Python、配置 CUDA、下载训练数据或重新训练。当前不提供 macOS、Linux、Windows ARM 原生安装包。

1. 在 GitHub Releases 打开 **v0.1.0**，下载 `FaceGuard-v0.1.0-windows-x64-cpu.zip`，不要下载下方的 `Source code`。
2. 右键 ZIP → **全部解压**，例如解压到 `D:\FaceGuard`。保留整个文件夹，不能只拿走 EXE。
3. 打开解压后的 `FaceGuard` 文件夹，双击 **FaceGuard.exe**。
4. 点击 **选择照片** 或 **选择视频**，确认中间预览，再点蓝色 **开始检测**。
5. 在右侧查看结果，需要时点击 **保存检测报告**。

默认照片检查 AI 整脸生成，默认视频检查换脸/面部篡改。照片要检查换脸时，在上方「检测项目」选择「换脸 / 面部篡改」。这两个任务不是同一件事。

程序使用 CPU，不要求独立显卡；照片通常比视频处理快，首次打开检测模型需要等待。文件在本机处理，不上传网络。发布包没有个人照片、训练图片或数据集示例，请选择自己的文件。

## 遇到问题

- **提示文件缺失或校验失败**：重新完整解压 ZIP；不要只复制 EXE，也不要在压缩软件里直接运行。
- **窗口出现但不知道点什么**：先选左边的照片/视频按钮，再点蓝色「开始检测」。没有选文件时，开始按钮会禁用。
- **未找到可分析的人脸**：表示无法判断；请换人脸更清楚的图片，不等于文件真实。
- **分数很高**：只是模型倾向于生成/篡改，不是“几乎肯定为假”的证明。
- **启动失败**：保留弹窗中的错误，诊断日志位于 `%LOCALAPPDATA%\FaceGuard\startup.log`。向项目反馈时可附程序版本和错误信息，不必提交个人图片。

已经检查运行资源、CPU 模型与移动目录后的启动。不同队友电脑的处理器和系统组件可能存在差异；第一次在实际队友机器上使用仍需要完成一次安装包验收。

程序不是鉴定机构，也不是所有 AI 图片和视频的通用检测器。大白话版限制见 `PROJECT_LIMITATIONS_PLAIN.md`，模型来源与实验范围见 `MODEL_CARD.md`。
