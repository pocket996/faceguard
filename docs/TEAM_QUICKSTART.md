# 队友使用说明

## 正式项目：谛听检测应用（2026-10-31）

正式应用独立入口为根目录 `run_app.cmd`，代码在 `src/faceguard/`。首次在根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-ui.txt
.\.venv\Scripts\python.exe run_app.py
```

以后可直接双击 `run_app.cmd`。Qt Quick 的连续网格形变需要可用的图形驱动；只预览界面可不加载模型；实际检测需要项目推理依赖与完整 `weights/runtime/`，不需要训练数据。已有完整旧参考资源时，运行根目录 `scripts/migrate_reference_models.py` 复制并核验一次；其他电脑可复制已核验的整个 runtime 资源目录，正式运行不依赖 `reference_run`。此入口尚未制作新的免安装发布包。

1. 在左侧选择或拖入本机照片 / 视频，照片支持放大，视频支持静音播放 / 暂停。文件不会上传网络。
2. 中央谛听已换为原效果图同源角色素材。点击可点头回应；“预览倾听动作”展示轻微移动、侧倾与涟漪，可随时停止。通过同一张透明纹理的网格形变实现轻呼吸与尾摆，不轮换姿态图；这是 2.5D 展示，尚非精细骨骼 3D 动画。
3. 点击右上角“收为桌宠”，主工作台切换为透明小窗口。拖动角色调整位置；双击或点击“展开”返回工作台，所选文件保留。也可通过 `run_app.py --pet` 直接启动桌宠。
4. 右键角色可选择媒体、置顶、减少动效、暂时隐藏和退出。隐藏后从系统托盘双击恢复；不支持托盘时改为最小化。设置与桌宠停靠位置保存在本机。
5. 导入后点击“开始检测”，照片分别检查 AI 整脸生成与面部篡改，视频使用篡改模型。按钮可取消，后台加载模型或当前采样步骤结束后响应取消。进度按实际阶段与样本数量显示；两项分数不合并，动作预览独立于检测。
6. 右侧“查看结果与热力图”进入独立大幅结果页。可切换原图、热力图叠加和并排对比，并缩放、拖动；选择右侧人脸可查看分数、阈值与裁剪图；视频同时显示对应采样帧。检测后可保存 JSON / 文本报告。真实热力图算法尚待实现，叠加区显示等待。热力图解释模型关注区域，不是已验证的精确篡改定位。
7. 右上角“历史”位于“设置”旁，可搜索文件名、筛选照片 / 视频、重新打开、删除与清空。记录保存在本机应用数据目录的 SQLite 库，保存路径、导入信息和真实检测结果，不复制原文件。导入时为“待检测”，检测后记录完成 / 部分完成 / 失败 / 取消状态；重新打开可恢复结果且不重复记一条，文件大小或修改时间变化后要求重新检测，文件移动后会提示找不到。清除记录不删除原始文件。
8. **设置 → 查看角色立体预览** 打开同一形象的 20 骨骼真实 3D 谛听，默认播放呼吸 / 摆尾与眨眼；“点头回应”“侧耳倾听”已放大幅度，包含预备、停留与回弹，播完回到待机；切换时平滑回正，可暂停 / 继续。拖动、滚轮或按钮可旋转，点击“恢复朝向”回到主视角；关闭后卸载场景。开启“减少动态效果”时保持静止、动作按钮禁用。工作台 / 桌宠仍使用既有 2.5D 动效；已有独立眼部 / 眼睑几何，完整面部表演、行走及跨窗口移动仍待制作；口鼻、折耳、闭眼形态及材质接缝仍待精修，尚非动画电影成品。

2026-10-30 交互补充：桌宠展开 / 收起增加淡出淡入与连续点击保护，开启“减少动态效果”则立即切换；这不是角色跨窗口行走。点击角色点头回应，悬停轻微侧头，双击可在工作台 / 桌宠间切换，拖动超过阈值后才移动桌宠。结果页并排图同步缩放与拖动，点击“适应”复位。快捷键：`Ctrl+O` 选择照片、`Ctrl+Shift+O` 选择视频、`Ctrl+H` 历史、`Ctrl+R` 结果、`F1` 说明、`Esc` 停止动作预览。

角色素材使用内置 imagegen 以原设定为参考生成，保存在 `src/faceguard/ui/assets/diting-v2.png`，生成说明见同目录 README。立体预览已有坐姿表演与眼睑控制，完整面部 / 四足行走绑定、桌宠连续走入中央 / 返回停靠点与自由巡游尚未完成。透明窗口的周边仍属于矩形窗口输入范围；多显示器、不同 DPI、视频编码兼容和其他队友机器仍需实际验收。

开发验收：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p test_desktop_ui.py -v
.\.venv\Scripts\python.exe scripts/check_desktop_ui.py
```

后者打开实际 Qt 窗口，检查同源角色资产、连续网格动效、模式切换、结果页与历史页，并将截图与报告写入被忽略的 `outputs/desktop-ui-check/`。不运行训练或参考项目推理。

### Blender 角色资产工具（本机，2026-10-30）

用户已授权下载与调用 Blender。本机安装官方 Windows x64 便携版 **4.5.15 LTS**，路径为 `D:\tools\blender\blender-4.5.15-windows-x64\blender.exe`；未修改系统 PATH，其他队友需各自安装并使用自己的实际路径。官方下载 ZIP 已与官方 `.sha256` 清单核对。

```powershell
& 'D:\tools\blender\blender-4.5.15-windows-x64\blender.exe' --background --factory-startup --python-exit-code 1 --python scripts/check_blender.py -- --output outputs/blender-setup
```

## 已有参考项目：v0.1.0 免安装包

这个发布包适用于 **Windows 10/11，64 位 Intel/AMD 电脑**。它已经包含 Python、CPU 检测程序和两份模型；不需要安装 Python、配置 CUDA、下载训练数据或重新训练。当前不提供 macOS、Linux、Windows ARM 原生安装包。

1. 在 GitHub Releases 打开 **v0.1.0**，下载 `FaceGuard-v0.1.0-windows-x64-cpu.zip`，不要下载下方的 `Source code`。
2. 右键 ZIP → **全部解压**，例如解压到 `D:\FaceGuard`。保留整个文件夹，不能只拿走 EXE。
3. 打开解压后的 `FaceGuard` 文件夹，双击 **FaceGuard.exe**。
4. 点击 **选择照片** 或 **选择视频**，确认中间预览，再点蓝色 **开始检测**。
5. 在右侧查看结果，需要时点击 **保存检测报告**。

默认照片检查 AI 整脸生成，默认视频检查换脸/面部篡改。照片要检查换脸时，在上方「检测项目」选择「换脸 / 面部篡改」。这两个任务不是同一件事。

程序使用 CPU，不要求独立显卡；照片通常比视频处理快，首次打开检测模型需要等待。文件在本机处理，不上传网络。发布包没有个人照片、训练图片或数据集示例，请选择自己的文件。

## 遇到问题

- **提示文件缺失或校验失败**：重新完整解压 ZIP；不要只复制 EXE，也不要在压缩软件里直接运行。
- **窗口出现但不知道点什么**：先选左边的照片/视频按钮，再点蓝色「开始检测」。没有选文件时，开始按钮会禁用。
- **未找到可分析的人脸**：表示无法判断；请换人脸更清楚的图片，不等于文件真实。
- **分数很高**：只是模型倾向于生成/篡改，不是“几乎肯定为假”的证明。
- **启动失败**：保留弹窗中的错误，诊断日志位于 `%LOCALAPPDATA%\FaceGuard\startup.log`。向项目反馈时可附程序版本和错误信息，不必提交个人图片。

已经检查运行资源、CPU 模型与移动目录后的启动。不同队友电脑的处理器和系统组件可能存在差异；第一次在实际队友机器上使用仍需要完成一次安装包验收。

程序不是鉴定机构，也不是所有 AI 图片和视频的通用检测器。大白话版限制见 `PROJECT_LIMITATIONS_PLAIN.md`，模型来源与实验范围见 `MODEL_CARD.md`。
